# Decisions

Record important product, technical, and execution decisions here.

## Product Brief

**What are we building?**
A professional qualifications resume showcase site — `my-qual-resume` — built with Next.js 16, React 19, TypeScript, and Tailwind CSS v4.

**Who is it for?**
The site owner — to present their qualifications, experience, skills, and professional profile to potential employers or clients.

**What does success look like?**
A polished, fast, accessible resume site that clearly communicates the owner's professional value, is easy to maintain, and looks great on all devices.

## Technical Decisions

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4
- **Language**: TypeScript
- **Agent system**: Masterbuilder multi-agent infrastructure copied from terrysc107-cloud/masterbuilder
- **Branch**: `claude/setup-masterbuilder-agents-4khVw`
